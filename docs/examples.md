# Examples

The `examples/` directory contains sanitized sample outputs that demonstrate the reporting format used by the research framework.

Files:

- `sample_trade_log.csv`
- `sample_monthly_returns.csv`
- `sample_equity_curve.png`

These examples are synthetic and anonymized. They are intended to show data structure, reporting style, and analytical workflow without exposing proprietary strategy logic, real production parameters, or private trading records.

## Sample Trade Log

The trade log demonstrates position-level records with entry/exit timestamps, return percentage, notional exposure, and adverse excursion.

## Sample Monthly Returns

The monthly returns file demonstrates month-by-month portfolio reporting.

## Sample Equity Curve

The equity curve image is a visual example of how portfolio performance and drawdowns can be summarized for review.
